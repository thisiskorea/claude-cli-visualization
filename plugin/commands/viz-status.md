# Visualization Status

Display the current status of the visualization daemon and session statistics.

## Instructions

1. Execute: `claude-viz status`
2. Parse and display the output including:
   - Daemon running status (yes/no)
   - Data directory location
   - Number of sessions recorded
   - Database size
   - Queue status
3. If daemon is running, show the web viewer URL
4. If daemon is not running, suggest using `/viz-start`

Present the information in a clear, formatted way.
