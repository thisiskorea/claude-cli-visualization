# Claude CLI Visualizer Skill

Helps you visualize and analyze your Claude CLI sessions.

## Usage

This skill provides tools to:
- Start/stop the visualization daemon
- View session statistics
- Export sessions for sharing
- Monitor tool usage and costs

## Available Commands

### Start Visualization
```
Start the Claude visualization daemon
```

### View Sessions
```
Show me my recent Claude CLI sessions
```

### Export Session
```
Export session [session-id] as HTML
```

### Get Statistics
```
Show visualization statistics
```

## Setup

1. Install: `npm install -g claude-cli-viz`
2. Initialize: `claude-viz init`
3. Start: Use this skill to start the daemon
4. View: Open http://localhost:3456

## Features

- 📊 Real-time session tracking
- 🎯 Tool usage analytics
- 📈 Token & cost tracking
- 🌳 File change visualization
- ⏱️ Timeline view
- 📤 Export & share sessions
